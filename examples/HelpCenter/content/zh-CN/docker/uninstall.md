# 卸载 Docker

卸载 Docker 会移除本地引擎及其服务。容器、镜像、卷和配置可能仍会保留，直到你明确删除它们。

## 开始前

- 导出需要保留的镜像或卷。
- 停止依赖 Docker 的工作负载。
- 保存之后重新安装所需的 compose 文件和镜像仓库凭据。

## 移除引擎

1. 使用 Linux 发行版的软件包管理器移除 Docker Engine 及相关软件包。
2. 若软件包管理器没有完成该操作，请禁用 Docker 服务。
3. 验证命令已不可用。

```bash
docker --version
```

## 可选的数据清理

Docker 数据通常位于 `/var/lib/docker`。只有确认其中没有仍需保留的镜像、卷或容器数据后才可删除；此操作不可恢复。
