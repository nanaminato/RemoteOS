# Docker をアンインストールする

Docker を削除すると、ローカル Engine とそのサービスが削除されます。コンテナー、イメージ、ボリューム、設定は明示的に削除するまで残ることがあります。

## 始める前に

- 保持するイメージまたはボリュームをエクスポートします。
- Docker に依存するワークロードを停止します。
- 再インストール時に必要な compose ファイルとレジストリ資格情報を記録します。

## Engine を削除する

1. Linux ディストリビューションのパッケージマネージャーで Docker Engine と関連パッケージを削除します。
2. パッケージマネージャーが実施しなかった場合は Docker サービスを無効にします。
3. コマンドが利用できなくなったことを確認します。

```bash
docker --version
```

## 任意のデータ削除

Docker のデータは通常 `/var/lib/docker` にあります。必要なイメージ、ボリューム、コンテナーデータが残っていないことを確認してから削除してください。この操作は元に戻せません。
