# Docker をインストールする

このガイドでは Linux サーバーに Docker Engine をインストールします。利用できる場合は、使用中のディストリビューション向けの公式 Docker パッケージを使用してください。

## 始める前に

- サーバーの管理者権限を持っていることを確認します。
- サーバーから Docker のパッケージリポジトリに接続できることを確認します。
- 新しい Engine を導入する前に、古い Docker パッケージを確認します。

## インストール

1. サーバーの Linux ディストリビューション向け Docker Engine 手順に従ってインストールします。
2. Docker サービスを開始し、自動起動を有効にします。
3. デーモンが動作していることを確認します。

```bash
docker --version
docker info
```

## RemoteOS で確認する

Docker Manager を開き、ステータスカードに Engine が利用可能と表示されるまで待ちます。利用できない場合はサービスログを確認し、現在のユーザーが Docker socket にアクセスできることを確認してください。
